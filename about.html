About COGNATION

COGNATION is a placeholder brand for this static starter. Replace the name in js/brand.js, then adjust copy and colors when you know your real product story.

Mission (starter copy)

Help teams publish a clean, accessible web presence without a frontend build pipeline. COGNATION ships as plain files so you can host it on nginx, Apache, or any static file server—including Oracle Linux.

What “COGNATION” means here

The instance brand is COGNATION. Treat it as a renameable label: edit js/brand.js (SITE_BRAND) and every [data-brand] spot updates together.

Design principles

Deep navy and indigo backgrounds with cyan accents keep the look distinct and professional. Shared header and footer keep navigation predictable. Mobile navigation works with a small script—no UI framework required.

Working with Grok Bot

Use the Grok Bot link whenever you need help drafting copy, refining layout ideas, or planning the next page. The site links out only—it does not embed a chat widget.
